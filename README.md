# Milap Publications

Static marketing site for Milap Publications — a fidelity recreation of the [Michael Hurley](https://michaelhurley.framer.website/) Framer template (by Raduan), using Milap brand content and assets.

## Stack

Self-contained `index.html` with inline CSS and JavaScript. No build step.

## Run locally

```bash
npx serve .
# or
python -m http.server 8799
```

## Deploy

Hosted on [Vercel](https://vercel.com). Site root is `index.html`; images load from the Storebox CDN.
